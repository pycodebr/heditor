# Named styles

Each file is a reproducible visual language. Rebuild the scenes from the new speech every time; never stamp a previous edit.
All fonts mentioned in the styles are installed by `setup.sh` and copied into each cut by `rk.setup_assets()` (Anton, VT323, Geist, Inter, JetBrains Mono, IBM Plex Mono, Press Start 2P, Playfair Display, Fraunces, Bebas Neue, DM Serif Display, Caveat, B612 Mono, Fredoka). Music ids refer to `assets/catalog.json`. A few newer styles use extra OFL families from google/fonts that you download into the cut with their `OFL.txt` (Bungee, Alfa Slab One, Tilt Neon, Barlow Condensed, IBM Plex Sans Condensed, Kalam, Cinzel, Cormorant Garamond, Abril Fatface); each style file says which.

Styles marked **layers** are creator formats built on depthkit (speaker matte, depth map, scans, hand tracking; see `../depth-and-3d.md`); styles marked **creator** reuse the same layouts without requiring the matte. Both families come from a technique study of high-retention tech-creator Reels (`../technique-catalogue.md`).

Styles marked **native** are deliberately minimal: cuts at clean word boundaries, jump cuts that read as new shots and animated word-by-word captions, with no music, SFX, graphics or end card unless the user asks. `nativo` ships a reference build (`heditor new <work> <video> --style nativo`, then `heditor produce <work> none 0`).

Styles marked **didactic** are explainer formats where the screen teaches what the speaker says: the diagram is drawn live, each stroke starting on the word that triggers it (recipe "Drawing synced to speech" in `../troubleshooting.md`).

Four styles ship a runnable reference build driven by a `beats.json` written from the speech (`heditor new <work> <video> --style <slug>`): `gravidade` (baked rigid-body physics, `../physics-3d.md`), `circuito` (GSAP plugins DrawSVG, MorphSVG, MotionPath and SplitText with SVG icons merged by `svgkit`, `../gsap-craft.md`) `lapidacao` (presenter matte on a black void, generated object photos, a louder score; assets in `scripts/reelkit/lapidacao_kit.py`) and `reacao` (speaker cutout in front of the post; backdrops from screenshots, `heditor capture`, `heditor region` or a clip; `scripts/reelkit/reacaokit.py`).

Styles marked **ad** are paid-traffic formats with a "Learn more" CTA and the ad safe area (`../captions-and-layout.md`, Paid-ad variant). Styles marked **authority** are serious formats where the speaker is the expert (sober palette with one accent, large central camera with a true name strip, the rule as the on-screen title).

Every style is also a **style pack** for long-form and multi-format edits (16:9, 1:1, 4:5…): palette, typography, captions, frame, transitions, chapter card, lower third, camera grade and sound, with the vertical → horizontal adaptation of each style in `../long-form.md` (`heditor long styles`).

Not listed? Use creative mode (`../creative-mode.md`) and, if the user likes the result, add the new style (`../adding-styles.md`).
